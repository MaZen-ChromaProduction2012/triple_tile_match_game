# 🧩 Triple Tile Match - Mobile Puzzle Game

لعبة ألغاز ومطابقة ثلاثية (Triple Tile Match) تعمل بالكامل على الهاتف باللمس، مبنية بـ HTML5 و CSS و JavaScript.

## ✨ المميزات الرئيسية
- **طبقات ثلاثية الأبعاد (Multi-layer 3D Tiles)**: تصميم جذاب للبلاطات متراصة فوق بعضها، حيث لا يمكن لمس البلاطات المغطاة حتى يتم إخلاء البلاطات العليا.
- **شريط تجميع سفلي (7 Slots Tray)**: تجميع ذكي للبلاطات مع إعادة ترتيبها تلقائياً بجانب الأشكال المشابهة ومطابقتها فور اكتمال 3 أشكال.
- **شاشة رئيسية وخريطة مراحل تفاعلية**: خريطة مغامرة متعرجة مقسمة إلى 4 مناطق بيئية (الحديقة، المحيط، الغروب، قلعة النجوم).
- **متجر البلاطات والثيمات (In-Game Shop)**: 4 مجموعات أشكال بلاطات (فواكه، حيوانات، حلويات، جواهر ملكية) و6 ثيمات خلفيات قابلة للشراء بالعملات الذهبية.
- **عجلة الحظ ومكافأة يومية**: عجلة دوارة لربح العملات والقدرات، وصندوق مكافأة يومية (+120 عملة).
- **وضع تحدي الوقت السريع**: تحدي السرعة مع مؤقت زمني وإضافة +4 ثوانٍ لكل مطابقة ومضاعفة العملات.
- **نظام الإنجازات والمهام (Achievements)**: تتبع تقدم اللاعب ومنح مكافآت عملات عند تحقيق الأهداف.
- **اهتزاز تفاعلي (Haptic Vibration)**: دعم كامل لاهتزاز الهاتف عند اللمس والمطابقة مع إمكانية التفعيل/الإيقاف.
- **3 مستويات صعوبة**: (سهل 🌱، متوسط ⚡، صعب 🔥) تؤثر على كثافة الطبقات والوقت ومكافآت العملات.
- **4 قدرات مساعدة**: تراجع ↩️، تلميح ذكي 💡، خلط البلاطات 🔀، وتفريغ 3 بلاطات إلى الرف المؤقت 📤.
- **مؤثرات صوتية مدمجة**: عبر Web Audio API بدون الحاجة لأي ملفات صوتية خارجية.
